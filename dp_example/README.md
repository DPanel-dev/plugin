# 配置展示示例

用于核对插件配置如何传入容器，并通过插件页面展示，适合开发和调试插件时参考。

## 可以验证什么

- **基础输入**：文本、多行文本和数字。
- **选择项**：单选显示模式、多选标签。
- **分组配置**：外观设置，以及可增加、删除实例的联系人分组。
- **配置传递**：页面请求插件服务的 `/api/test`，展示服务启动时读取的环境变量；联系人 `CONTACTS` 按原始字符串展示。

## 使用说明

1. 准备展示标题、展示内容等示例配置。服务端口默认为 **18080**，运行前确认宿主机端口可用。
2. 部署示例容器后打开插件页面，对照配置值检查接口返回和页面展示。
3. 修改配置后更新并重新创建容器，再刷新页面核对结果。

示例服务同时提供页面和配置接口。页面将配置作为文本展示，主题颜色、显示模式等字段用于验证值的传递，不会改变页面样式。

配置接口会直接返回示例环境变量，请勿填写密码、令牌或其他敏感信息。
